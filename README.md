# allbark.dev

The website for All Bark, a one-person indie studio. Served by GitHub Pages from `main`.

- `/` home, `/byte/*` and `/social/*` app policy and support pages (hand-written HTML, URLs fixed)
- `/devlog/` The Bark Log, our weekly devlog (Jekyll posts in `_posts/`; linked from the home page once the first post is live)

See [CONTRIBUTING.md](CONTRIBUTING.md) for how the site is built and how devlog posts are written.
